# X 平台日常养号任务数据补齐方案

## 目标
让「Twitter/X 日常养号」模板不再只是一个空模板：补齐用它创建出来的任务数据，覆盖全部任务状态与全部任务结果，并保证父任务、子任务、任务日志、统计、详情五处数据完全一致。

## 数据联动现状（无需重复造数）
系统里子任务、任务日志、统计卡片、分布 tab、详情弹窗全部由父任务的一条记录推导：
- 子任务：按 `总计 / 成功 / 失败 / 执行状态` 确定性展开
- 任务日志：同一套规则逐条展开事件链
- 统计：成功 + 失败 + 进行中 = 总计，成功率 = 成功 ÷ 已结束

所以只需新增设计合理的父任务记录，其余数据自动同步且天然一致。任务诊断中心是独立的大样本 mock，已包含养号 + X 平台样本，不改动。

## 合理性约束
- 每条都满足 成功 + 失败 ≤ 总计，差额即进行中 / 待执行
- 全部使用 X 平台真实托管账号（按平台取号，与账号列表一致）
- 养号策略沿用模板口径：兴趣关键词 + 点赞 / 关注 / 评论比例 + 英文搜索关键词
- 结束时间只给已结束的任务，创建人、创建时间、周期配置与现有养号任务风格保持一致
- 任务归属租户沿用现有轮转规则
