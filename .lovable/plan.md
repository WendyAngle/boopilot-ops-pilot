# 好友管理「关注」统一方案

## 目标
将好友管理的关注入口与私信管理统一，降低跨模块理解和操作成本。

## 调整内容
- 关注图标统一使用星标：未关注为空心星，已关注为琥珀色实心星。
- 操作文案统一为「关注 / 已关注」；点击后直接切换状态，并提示「已加入关注 / 已取消关注」。
- 所有好友关系状态共用同一个关注入口，不再让「已拒绝」记录显示一套独立的「标记关注 / 取消关注」操作。
- 提示文案统一说明：加入关注后可在「关注」分类中集中跟进。
- 「关注」分类标签同步增加星标图标和数量，选中时显示实心星，与私信管理的关注筛选保持一致。
- 再次申请提醒仍保留提醒图标，因为它表达的是新事件通知，不属于关注操作本身。

## 数据与范围
- 沿用现有关注状态和筛选逻辑，不改变好友申请、备注、撤回或私信跳转等其他功能。
- 收到的申请、我发起的申请、好友列表和已拒绝记录均可使用相同关注操作。

## 验证
- 分别验证未关注→关注、已关注→取消关注。
- 验证关注分类数量和列表即时同步。
- 验证已拒绝记录不再出现重复或不同文案的关注入口。
