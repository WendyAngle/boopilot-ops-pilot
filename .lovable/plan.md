# 私信任务「查看详情」弹窗调整方案

## 目标
仅调整任务列表中「私信任务」的查看详情弹窗，使信息围绕一次明确的私信执行展开：**一个目标账号、一个执行账号、一段已替换变量的私信内容、一个执行时间**。社媒触达及其它任务类型保持现状。

## 弹窗结构
私信任务保持 5 个区块，顺序如下：

1. **任务基本信息**
   - 保留：任务名称、平台、任务动作。
   - 删除：目标市场、推广产品。

2. **目标**
   - 原「寻找目标」更名为「目标」。
   - 仅展示「目标账号」，使用与该任务平台一致的确定性目标账号名称。
   - 删除寻找方式、搜索关键词、链接、活跃时间范围、目标数量上限。

3. **私信内容**
   - 保留：发送语种、私信原文、中文译文。
   - 展示前将 `{联系人名}` 替换为当前目标账号，将 `{我的公司}` 替换为执行账号所属租户，将 `{我的姓名}` 替换为任务创建人，确保弹窗不出现未解析变量。

4. **执行账号**
   - 仅展示一个真实托管账号，账号名称与账号列表、任务统计口径一致。
   - 删除「每账号每日上限」。
   - 将现有私信任务数据统一为每个任务一个执行账号，避免弹窗、子任务及统计出现多账号口径冲突。

5. **执行方式**
   - 固定展示「立即执行」。
   - 删除开始时间、结束时间。
   - 新增「执行时间」，取任务实际开始执行时间；保证同一任务在列表详情、子任务时间口径一致。

## 数据一致性处理
- 私信任务的目标账号按平台和任务稳定生成，同一任务每次打开保持一致。
- 私信任务种子数据的执行账号数量统一为 1；社媒触达任务仍保留多账号和周期执行规则。
- 私信原文与译文使用同一目标账号完成变量替换，不修改原始话术配置。
- 私信任务总量、成功数、失败数、状态及日志数据不变。

## 验收标准
- 任一私信任务详情中不再出现目标市场、推广产品、寻找目标配置、每日上限、开始时间或结束时间。
- 目标账号与私信中的联系人名一致，原文和译文均无 `{联系人名}`、`{我的公司}`、`{我的姓名}` 残留。
- 每个私信任务只显示一个账号，且为账号列表中的真实托管账号。
- 执行方式为「立即执行」，并展示唯一「执行时间」。
- 社媒触达任务及其它任务详情不受影响。

## 技术实施范围
- 调整任务列表详情弹窗，对私信任务使用独立展示分支，不改变社媒触达弹窗。
- 将目标账号选择与变量替换抽为稳定的共享规则，避免详情弹窗和子任务页面出现不同联系人。
- 修正私信任务 mock 数据的账号数量，并检查按账号统计与子任务数据仍保持一致。
