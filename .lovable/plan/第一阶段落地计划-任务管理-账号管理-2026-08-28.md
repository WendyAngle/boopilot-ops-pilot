# 第一阶段落地计划：任务管理 + 账号管理

## 目标

把「任务管理」与「账号管理」两个模块按 BooPilot 的自动驾驶式业务运营理念补齐核心功能，可演示真实运营流程。按功能页面逐页推进，每完成一页即可查看效果。

## 已确认前提

- 任务区分**子类型**：`action`（单次执行任务）与 `nurture`（周期养号任务），沿用现有 `TaskSubType` 定义
- 账号管理本阶段**只做托管账号**（账号列表 + 详情 + 健康看板），目标账号暂不动
- 任务创建**需要关联**目标账号与素材
- 交付节奏：按功能页面逐页推进

## 推进顺序（逐页交付）

### P1 托管账号列表（`/accounts/managed`）
筛选（平台 / 状态 / 租户 / 关键词）、分页、批量操作、导出入口，工具条新增「账号健康看板」按钮（带待处理红色角标）。

### P2 托管账号详情（`/accounts/managed/$id`）
基础信息与平台角标、状态 Badge、绑定设备/IP、最近任务列表、新增「状态记录」时间线。

### P3 账号健康看板（`/accounts/health`）
- 顶部状态统计卡片（沿用 `StatCard` 与 `ACCOUNT_STATUS_META` 配色）
- 状态数量变化趋势折线图（近 7 天 / 2 周 / 1 月 / 自定义）
- 分平台状态趋势：平台 Tabs + 堆叠面积图 + 平台×状态数量矩阵表（含环比）
- 账号状态台账表格：当前状态、平台侧状态、标记来源、需人工处理、处理状态/方式/结果、处理人与时间
- 处置闭环：人工确认状态弹窗、登记处理弹窗、状态时间线抽屉、批量标记已处理
- 侧边栏「账号管理」下新增同名菜单

### P4 任务列表（`/tasks/list`）
按子类型 Tab（全部 / 单次任务 / 周期养号）、状态与平台筛选、关键词搜索、分页、批量启停与删除。

### P5 任务创建
弹窗表单：任务名称、子类型、平台、指定托管账号（支持按标签批量选择）、关联素材（复用 `MaterialPicker`）、执行方式（立即 / 定时 / 周期）、数量与优先级。复用现有 `use-template-dialog` 的分步表单模式。

### P6 任务详情与日志（`/tasks/$taskId` 及 logs 子路由）
任务元信息、执行进度与成功率、关联账号与素材、执行日志与子日志跳转联动。

### P7 统一走查
各页 `head()` 元数据、空状态、加载态、移动端响应式、语义 token 检查。

## 技术要点

- 全部基于现有前端 mock / store（`managed-account-mock.ts`、`activity-tasks.ts`、`task-logs.ts`、`account-health-mock.ts`），不引入后端
- 健康看板新增趋势构造函数（确定性伪随机，末日数据与当前真实统计对齐）
- 图表使用已安装的 `recharts`，颜色全部走语义 token
- 组件复用 shadcn/ui、`StatCard`、`PaginationBar`、`TagMultiSelect`、`MaterialPicker`
