# 任务平台

作为一个资深的产品架构师和产品设计师，请你参考 https://boo-reach-hub.lovable.app/系统设计风格，创建一个新的业务系统，系统名称“BooPilot"("把自动驾驶的体验带给业务运营")

新系统功能模块如下，具体功能实现先留白，后面补充。

- 工作台

- 任务管理：运营任务

- 账号管理：托管账号、目标账号

- 素材管理：成品库

- 租户管理：租户列表

- 标签管理：标签管理

- 资源管理：设备列表、IP列表、镜像实例

- 智能体管理：智能体列表、模型配置

- 系统管理：用户管理、角色管理、部门管理
